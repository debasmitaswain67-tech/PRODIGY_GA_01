# 🤖 GPT-2 Fine-Tuning on KISS_SEOUL Dataset

This project focuses on fine-tuning the **GPT-2 language model** using custom data related to **KISS(Korean Independent School of Seoul)**. The implementation is done using **Google Colab**, making it easy to run and reproduce.

---

## 📌 Project Overview

- 🔹 Fine-tuned GPT-2 on a custom dataset  
- 🔹 Dataset contains domain-specific information about KISS  
- 🔹 Implemented using Python, Hugging Face Transformers, and PyTorch  
- 🔹 Executed on Google Colab for GPU acceleration
